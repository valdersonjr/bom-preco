# Artefatos — Bom Preço

Comparador colaborativo de preços de supermercado, para Goianésia–GO. Aplicativo web
instalável, com preços cadastrados pelos próprios usuários.

| Área | Conteúdo |
| ---- | -------- |
| [requisitos/](requisitos/) | Elicitação, análise, especificação e validação. Comece pelo [índice](requisitos/README.md) |
| [design/](design/) | [Esquema do banco](design/esquema.sql) e [decisões de design](design/design.md): persistência, acesso e tolerância a falhas |

**Para entender o projeto em quinze minutos:** [Visão](requisitos/1-elicitacao/visao.md) →
[modelo de domínio](requisitos/2-analise/modelo-de-dominio.md) → [esquema](design/esquema.sql).

**Para começar a construir:** aplicar o esquema num projeto Supabase, carregar os catálogos
de Goianésia e o recorte do Open Food Facts. É o marco 1 do cronograma na Visão.
